## 6. `ai/predictor.py` 모델 로직 분석

predictor.py는 **완전히 결정론적(heuristic)인 오프라인 예측 엔진**입니다.
외부 ML 서비스 없이 최근 30일 게임 로그와 간단한 규칙으로 모든 예측을 생성합니다.

### 6.1 입력 데이터

- `GameLog` 테이블에서 **현재일 기준 최근 30일**의 동일 스포츠 경기만 필터링
- 팀별 홈/원정 득실점 집계, 최근 10경기 diff 리스트
- 상대 전적(H2H): 같은 두 팀이 최근 30일 pool에서 맞붙은 횟수

### 6.2 핵심 가중치 및 로직

#### A. 머니라인 (`_predict_moneyline`)

```
h_str = 0.6 * win_pct + 0.4 * (0.5 + diff / max(1, games * 2))
a_str = 0.6 * win_pct + 0.4 * (0.5 + diff / max(1, games * 2))
```

- **팀 강도** = 승률 60% + 득실차 기반 조정 40%
- H2H가 2경기 이상 있으면 `h_str = 0.75 * h_str + 0.25 * h2h_home_win_pct` 로 반영
- **홈 어드밴티지**: baseball/football/hockey는 +3%, basketball/volleyball는 +2%
- **calibration**: 확률을 50~85% 밴드로 압축 (과신 방지). football/hockey는 무승부 확률 추가

#### B. 핸디캡 (`_predict_handicap`)

```
pace = home.ppg_for + away.ppg_for
exp_margin = home.ppg_for - away.ppg_for
line = round((exp_margin + gap * 1.2), 1)
cover_p = _logistic((exp_margin - line) * 1.2 + gap)
```

- 예상 마진 + ML 확률 갭을 선형 결합하여 라인을 생성
- 커버 확률은 시그모이드(로지스틱) 함수로 0~1 매핑

#### C. 토탈 (언더/오버) (`_predict_totals`)

```
line = {baseball: 8.5, football: 2.5, basketball: 165.5, volleyball: 180.5, hockey: 5.5}
exp = home.ppg_for + away.ppg_for
exp_blend = 0.7 * exp + 0.3 * line  # 회귀를 통한 과적합 방지
over_p = _logistic((exp_blend - line) * 1.5)
```

- 날씨(풍속) 효과: 야외 경기(baseball, football)에서만 -0.04×(w-2) 또는 -0.02×(w-3) 조정
- 실제 라인을 30% 반영하여 극단적인 runs 예측을 억제

#### D. 가치베트 (`_value_bet`)

```
if fav_stats["win_pct"] >= 0.6 and edge <= 12:
    return True, ...  # [가치 역배]
```

- **조건**: 최근 30일 승률 60% 이상이면서 시장 배당 격차가 12%p 이하일 때
- 즉, 성적은 좋은데 시장이 과소평가한 경우만 "value_bet"로 마킹
- 신뢰도 점수에 +8 보너스 반영

#### E. 신뢰도 점수 (`confidence`)

```
conf = max(ml_prob) + (8 if value_bet else 0) + ((nrfi_pct - 50) / 6)
conf = max(45.0, min(96.0, conf))
```

- ML 최고 확률을 베이스로, value_bet이면 +8, NRFI/YRFI 확률 편차를 소폭 반영
- 하한 45, 상한 96으로 클램핑

#### F. 한계

1. **최근 30일만 사용**: 장기 트렌드, 시즌 전체 기록, 부상/트레이드 반영 불가
2. **가중치가 고정**: 0.6/0.4, 0.75/0.25 H2H 등은 데이터 기반 학습이 아닌 수동 규칙
3. **배당률 미사용**: 실제 마켓 odds를 입력받지 않으므로 value_bet은 내부 격차 기준
4. **날씨 의존성**: `crawler.weather.get_weather` 결과에 따라 토탈이 ±0.08 runs/goals 정도만 변동
5. **야구 NRFI 전용**: 다른 스포츠에는 첫 이닝/특수 이벤트 예측 없음

## 7. 결론

1. **예측 정확도 측정은 현재 불가능**합니다. 32개 예측이 모두 미해결이며, game_logs와의 game_id 연결도 없습니다.
2. 과거 `game_logs`만으로는 **승패/오버언더의 구조적 패턴**은 확인할 수 있습니다.
   - 홈승은 대부분 45~65% 범위
   - 농구는 99% OVER, 배구 72.6% OVER, 하키 38% UNDER
3. ROI 시뮬레이션은 **단순 규칙 전략** 기준이며, 실제 predictor 출력과의 비교가 필요합니다.
4. predictor.py는 가벼운 heuristic 모델로, 최근 30일 성적 + 홈어드밴티지 + H2H로 작동합니다.
   실제 예측 대비 과거 정확도를 측정하려면 `predictions` → `resolved=1` 데이터와
   game_logs와의 game_id 매핑이 선행되어야 합니다.
